# RASCI Matrix Template
**Responsibility Assignment Matrix for Cross-Functional Projects**

---

## What is RASCI?

**R** = **Responsible** — Does the work
**A** = **Accountable** — Owns the decision (only one person)
**S** = **Support** — Provides resources or assistance
**C** = **Consulted** — Provides input (two-way communication)
**I** = **Informed** — Kept in the loop (one-way communication)

## Tips for Using This RASCI

1. **Only ONE "A" per row** — Accountability must be clear
2. **Avoid too many "C"s** — Consultation slows decisions; be selective
3. **Update as the project evolves** — Roles may shift between phases
4. **Use in kickoff meetings** — Get buy-in early
5. **Reference in reviews** — Keep team aligned on ownership
