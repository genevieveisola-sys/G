# How to Use These Assets in Canva
**Step-by-step guide for building your presentation in Canva**

---

## Getting Started

### 1. Create Your Presentation

1. Go to **https://canva.com**
2. Click **"Create a design"**
3. Select **"Presentation (16:9)"** — this gives you the standard 1920x1080 size
4. Name your project: "Grammarly Design Ops Presentation"

---

## Setting Up Your Design System

### 2. Create a Color Palette

Canva allows you to save custom colors. Add these to your brand kit:

**How to add colors:**
1. Click any text or shape
2. Click the color picker
3. Click the **"+"** button
4. Enter these hex codes:

```
Primary Colors:
#1E3A8A (Navy) — Use for titles and headers
#4A90E2 (Blue) — Use for Meta theme
#16A085 (Teal) — Use for accents

Secondary Colors:
#50C878 (Green) — Use for Blueprint/positive metrics
#BD10E0 (Purple) — Use for Ring theme
#F5A623 (Orange) — Use for Agency theme

Neutrals:
#374151 (Dark Gray) — Use for body text
#6B7280 (Gray) — Use for captions
#D1D5DB (Light Gray) — Use for backgrounds
#FFFFFF (White)
```

**Pro tip:** Click the three dots in your color picker → **"Add to brand colors"** to save them permanently.

---

### 3. Set Up Typography

Canva has excellent fonts. Use these as alternatives to the recommended fonts:

| Recommended | Canva Alternative |
|-------------|------------------|
| Inter | **Lexend** or **Manrope** |
| SF Pro Display | **Montserrat** or **Raleway** |
| Avenir | **Nunito Sans** or **Poppins** |

**Typography Scale:**
- **Slide Titles:** 60-72pt, Bold
- **Section Headers:** 36-42pt, Semibold
- **Body Text:** 20-24pt, Regular
- **Captions:** 14-16pt, Light
- **Large Metrics:** 72-90pt, Bold

**How to set default fonts:**
1. Click **"Brand Kit"** (left sidebar, only in paid version)
2. Or manually select fonts for each text box

## Rendering Diagrams for Canva

### 4. Convert Mermaid Diagrams to Images

**Step 1: Go to Mermaid Live**
- Open **https://mermaid.live/**

**Step 2: Copy Diagram Code**
- Open any diagram file (e.g., `diagrams/ouroboros_loop_diagram.md`)
- Find the Mermaid code block (starts with ` ```mermaid`)
- Copy everything between ` ```mermaid` and ` ``` `

**Step 3: Generate Image**
- Paste into Mermaid Live editor
- The diagram renders automatically
- Click **"Actions"** → **"PNG"** or **"SVG"**
- Download the file

**Step 4: Upload to Canva**
- In Canva, click **"Uploads"** (left sidebar)
- Click **"Upload files"**
- Select your downloaded diagram
- Drag it onto your slide

**Diagrams to render:**
- `ouroboros_loop_diagram.md` → Slide 2
- `stakeholder_network_map.md` (Meta) → Slide 7
- `stakeholder_network_map.md` (Ring) → Slide 15

## Building Key Slides

### Slide 1: Title / Introduction

**Canva Steps:**
1. Start with a blank slide
2. Add text: Click **"Text"** → **"Add a heading"**
3. Type: **"CONNECTING PEOPLE, DESIGN, AND SYSTEMS THAT SCALE"**
   - Font: **Montserrat Bold**, 72pt
   - Color: #1E3A8A (Navy)
   - Center-aligned
4. Add subheading: **"By Genevieve Isola — Design Program Leader"**
   - Font: **Montserrat Regular**, 36pt
   - Center-aligned, below title
5. Add tagline: **"Tagline: Design Ops as a Design Discipline"**
   - Font: **Montserrat Light Italic**, 28pt
6. Add footer text: **"24 slides · 45 minutes · 2 case studies"**
   - Font: **Lexend Light**, 14pt
   - Color: #6B7280 (Gray)
   - Bottom of slide
7. Optional: Upload a headshot
   - Click **"Uploads"** → Upload your photo
   - Resize small, place in bottom-right corner

**Pro tip:** Use Canva's alignment guides (pink lines) to center everything perfectly.

### Slide 2: Philosophy — The Ouroboros Approach

**Canva Steps:**

**Left Side: Ouroboros Diagram**
1. Upload your rendered Mermaid diagram (see Step 4 above)
2. Drag onto slide, resize to fill left 60% of slide
3. Or create manually:
   - Use **"Elements"** → Search **"circle"**
   - Add 8 text boxes around the circle (Listen, Align, Build, Prove, Scale, Measure, Inform, Iterate)
   - Use arrows (**"Elements"** → **"Lines & shapes"** → Arrow) to connect stages
   - Color each stage differently using your palette

**Right Side: Three Pillars**
1. Click **"Text"** → Add heading
2. Type: **"THREE PILLARS"**
   - Font: **Montserrat Bold**, 42pt
3. Add three text boxes below:
   - **"1. PEOPLE-FIRST CLARITY"** (36pt, bold)
   - "Make sure people can do their best work" (20pt, regular)
   - (Repeat for pillars 2 and 3)
4. Add icons (optional):
   - Click **"Elements"** → Search **"people icon"**, **"shield icon"**, **"speed icon"**
   - Place next to each pillar

**Footer:**
- Add small icons + text for metrics
- **"Elements"** → Search **"clock icon"** → type "Faster time-to-decision"

## Tips for Efficiency in Canva

### Use Templates
- Search Canva templates for **"professional presentation"**
- Pick one with clean layouts
- Replace content with your material
- Adjust colors to your palette

### Duplicate Slides
- Once you create one metric card, duplicate it
- Right-click slide → **"Duplicate slide"**
- Or duplicate elements within a slide (Cmd/Ctrl + D)

### Use Grids & Alignment
- **"Position"** → **"Tidy up"** to auto-align elements
- Use pink alignment guides while dragging
- **"Arrange"** → **"Distribute"** to space evenly

### Create Reusable Elements
- Design one metric card perfectly
- Copy/paste for all other cards
- Just change text and numbers

### Brand Kit (Canva Pro)
- Upload logos, save colors, set default fonts
- Makes consistency easier across all slides

## Animations in Canva

### Add Slide Transitions
1. Click a slide
2. Click **"Animate"** (top toolbar)
3. Choose transition style (e.g., **"Fade"**, **"Slide"**)
4. Set duration (0.5-1s recommended)

### Animate Elements
1. Select an element (text, image, shape)
2. Click **"Animate"**
3. Choose animation:
   - **"Fade"** — For text appearing
   - **"Rise"** — For metrics counting up (visual effect)
   - **"Pan"** — For diagrams
4. Set order (1, 2, 3...) for sequential animations

**Recommended Animations:**
- **Slide 2 (Ouroboros):** Fade in diagram, then fade in pillars
- **Slide 10 (Metrics):** Cards appear sequentially (Rise animation)
- **Slide 3 (Case Studies):** Cards slide in from left and right

## Exporting Your Presentation

### For Presenting
1. Click **"Share"** → **"Present"**
2. Use Canva's present mode (full screen)
3. Or download: **"Download"** → **"PDF (print)"** for handouts

### For Sharing
1. Click **"Share"** → Get shareable link
2. Or **"Download"** → **"PDF (standard)"**

### High Quality
1. **"Download"** → **"PNG"** (individual slides, 2x resolution)
2. Good for email or portfolio

## Canva Pro Tips

### If You Have Canva Pro:
- Use **Background Remover** on your headshot
- Use **Brand Kit** to save your design system
- Use **Magic Resize** to create other formats (e.g., 4:3)
- Access more premium templates and elements

### If You Have Canva Free:
- Everything above still works!
- Just manually apply colors/fonts each time
- Use free elements and icons
- Limit to 5 brand colors (workaround: use color picker)
